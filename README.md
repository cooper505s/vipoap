# VIPOAP website

Production-ready static website for GitHub and Cloudflare Pages.

## Publish
Upload the contents of this folder so `index.html` is at the repository root. Cloudflare Pages requires no build command; use the repository root as the output directory.

## Contact form
The callback form sends to `help@vipoap.co.uk` through FormSubmit. The first live submission may trigger a one-time activation email.

## Brand
The approved transparent PNG logo files in `assets/` are locked artwork and must not be regenerated or restyled.
