# The VIPOAP Way

The VIPOAP Way defines how we design, communicate and behave.

## People before technology

Technology is never the hero. People are.

## Kindness before speed

A fast answer is not useful if it leaves someone feeling confused or embarrassed.

## Trust before profit

We recommend what is right for the member, even when the simpler or cheaper option earns us less.

## Plain English before jargon

We explain. We do not impress.

## Confidence before dependency

Our aim is to help people feel capable, not make them reliant on us.

## Calm before clever

Simple, reassuring experiences are better than feature-heavy ones.

## Privacy before convenience

Personal information is collected only when needed, protected carefully and retained only for a clear purpose.

## One home, one story

Bookings, visits, devices, help requests and scam checks should form one understandable household history.

## Every visit adds value

Each visit should leave the home better documented, the member better informed and the next interaction easier.

## The Kitchen Table Test

Before approving any page, message or feature, ask:

> Would this make sense if we explained it to someone calmly at their kitchen table?

If not, simplify it.

## The Margaret Test

Could Margaret, aged 78, understand what to do without needing someone else to explain the screen?

If not, redesign it.
