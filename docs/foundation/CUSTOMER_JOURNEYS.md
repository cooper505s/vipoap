# VIPOAP Customer Journeys

## Purpose

Every journey should help a person move from worry or uncertainty to confidence and clarity.

## Core journey rule

Each journey must:

1. Begin with the person's real concern.
2. Use plain English.
3. Ask for only the information needed at that moment.
4. Offer a clear human-help route.
5. End with reassurance and a clear next step.

## Public website journey

1. Visitor arrives from search, recommendation or social media.
2. The page explains who VIPOAP helps and how.
3. The visitor chooses one of four clear actions:
   - I would like some help.
   - Check if something is a scam.
   - Learn something new.
   - Call Dan.
4. The chosen path avoids unnecessary forms or technical wording.
5. The visitor receives confirmation of what will happen next.

## Booking journey

1. Choose the type of help.
2. Choose a 30-minute or 1-hour visit.
3. Choose from available dates and times only.
4. Enter contact and address details.
5. Review the request in plain English.
6. Submit.
7. Receive a friendly confirmation and booking reference.

The booking form must never imply an appointment is final until it has been accepted or automatically confirmed.

## Ask for Help journey

1. Describe what is happening in the customer's own words.
2. Select how they would prefer to be contacted.
3. Add a photo or screenshot only when useful.
4. Submit the request.
5. Receive a reference and simple status description.
6. Continue the conversation through the website or email.

Customer-facing status language:

- We have received your request.
- Dan is looking at this.
- We need a little more information.
- A visit has been arranged.
- This has been completed.

## Scam-check journey

1. Choose what was received: email, text, call, WhatsApp, website, parcel message, bank message or something else.
2. Paste the message or describe what happened.
3. Optionally attach one screenshot.
4. Receive one of four outcomes:
   - This looks likely to be a scam.
   - I would be careful with this.
   - There is not enough information yet.
   - This may be genuine, but verify it independently.
5. Read the reasons in plain English.
6. Follow immediate safety steps.
7. Send it to Dan for review when needed.

The checker must never guarantee that a message is safe.

## Family-member journey

A trusted family member may, with permission:

- request help;
- arrange visits;
- submit scam checks;
- view agreed appointment information;
- receive relevant updates.

Private notes and sensitive household information remain hidden unless the member has explicit permission.

## Visit follow-up journey

After a visit, the household should receive:

- what was done;
- anything they need to remember;
- recommendations;
- the next suggested step;
- a clear way to ask another question.

## Journey review tests

Before release, every journey must pass:

- the Kitchen Table Test;
- the Margaret Test;
- keyboard-only completion;
- mobile completion;
- screen-reader review;
- plain-English review;
- failure and recovery testing.
