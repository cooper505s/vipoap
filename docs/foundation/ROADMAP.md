# VIPOAP Product Roadmap

## Roadmap principles

- Launch useful, trustworthy features before ambitious ones.
- Keep initial operating costs close to zero.
- Do not add complexity without customer benefit.
- Keep `main` deployable.
- Use feature branches and pull requests for significant changes.

## Release 1.0 — Public launch

Goal: win the first customers with a calm, professional public experience.

Includes:

- polished public website;
- consistent header, navigation, footer and page layouts;
- problem-led service pages;
- installable PWA;
- 30-minute and 1-hour booking requests;
- configurable availability;
- contact and callback routes;
- text-based scam checker MVP;
- basic Ask for Help request flow;
- plain-English privacy and accessibility information;
- analytics, SEO and deployment checks.

## Release 1.1 — Operational reliability

Goal: make the launch features dependable and manageable.

Includes:

- Cloudflare D1 production schema;
- secure admin authentication;
- booking and help-request administration;
- Resend email notifications;
- rate limiting and bot protection;
- audit logging;
- backup and export procedure;
- error monitoring;
- usability and accessibility fixes from real feedback.

## Release 1.5 — My Home

Goal: give members a simple, useful household area.

Includes:

- secure member sign-in;
- household profile;
- appointments and visit history;
- My Technology device records;
- visit summaries;
- scam-check history;
- trusted family access;
- communication and accessibility preferences.

## Release 2.0 — VIPOAP Core

Goal: provide one operational workspace for the business.

Includes:

- adviser dashboard;
- household timeline;
- full Ask for Help workflow;
- customer and household search;
- visit planning;
- Home Health Checks and technology scores;
- recommendations and follow-ups;
- Google Calendar integration;
- optional Zoho CRM synchronisation;
- membership management.

## Release 2.5 — Ask VIPOAP

Goal: provide safe, context-aware assistance while keeping human support available.

Includes:

- VIPOAP Safe for scam checks;
- VIPOAP Guide for plain-English help;
- VIPOAP Fix for guided troubleshooting;
- household-aware answers with permission;
- human escalation;
- AI usage controls, logging and cost limits;
- quality and safety evaluation.

## Release 3.0 — Growth

Goal: support a mature local operation and assess wider expansion.

Possible features:

- payments and subscriptions;
- automated reminders;
- route planning;
- reporting and service trends;
- family plans;
- richer knowledge content;
- additional advisers and role-based work allocation;
- evaluation of a wider VIPOAP adviser network.

## Not in the initial launch

The following should not delay Release 1.0:

- native iOS or Android apps;
- complex customer passwords;
- advanced reporting;
- national multi-tenant architecture;
- live chat staffing;
- remote monitoring of household activity;
- storing customer passwords;
- voice assistants;
- extensive membership automation.

## Release gate

A release is ready only when:

- the main journeys work on mobile and desktop;
- accessibility checks are complete;
- privacy and security controls are documented;
- failure states are understandable;
- support and rollback steps exist;
- the feature passes the Kitchen Table and Margaret tests.
