# VIPOAP training phase reminder

Start this phase after the VIPOAP OS operational build-out is complete.

- Build structured online courses made up of individual modules.
- Track module starts, progress, completion and attempts automatically.
- Mark completion only from the course workflow; engineers cannot edit their own status.
- Calculate and store assessment scores automatically.
- Set pass marks, retake rules and required modules centrally.
- Show each engineer their progress and results, with HQ reporting by engineer and territory.
- Link successful course completion to the services and work an engineer is authorised to provide.
