# VIPOAP franchise operating pack

This pack is the working foundation for expanding VIPOAP beyond the founding Andover territory while keeping the service safe, consistent and recognisably VIPOAP.

## Documents

- [Operating model](OPERATING-MODEL.md) — responsibilities, territory model, controls and customer journey.
- [Franchisee onboarding](ONBOARDING-CHECKLIST.md) — readiness checks from first assessment to go-live.
- [Pilot rollout](PILOT-PLAN.md) — a controlled 90-day launch plan for the first territory.
- [Brand standards](BRAND-STANDARDS.md) — approved identity, voice and customer promises.
- [Core service procedure](CORE-SERVICE-SOP.md) — the standard enquiry-to-aftercare workflow.

## Status

These are operational working documents, not a franchise agreement or legal, tax, employment, safeguarding or financial advice. Before selling a franchise, VIPOAP should have the complete model reviewed by a UK franchise solicitor, accountant, insurer and data-protection adviser.
