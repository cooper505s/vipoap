Accessibility

Making VIPOAP easy to use

We aim to meet WCAG 2.2 Level AA and make this website clear, readable and comfortable to use on phones, tablets and computers. Accessibility is reviewed as the service changes.

What the website supports

  • Keyboard navigation
  • Clear headings and link wording
  • Large touch targets
  • Readable colour contrast
  • Text resizing in modern browsers
  • Reduced motion preferences
  • Clear form labels, validation messages and status updates

Need help using the website?

Call 07977 254158 or email help@vipoap.co.uk. We can explain the information or help you complete a request another way.

Tell us about a problem

Please include the page you were using, what you were trying to do and the device or browser you used. We will investigate and make reasonable improvements where possible.

Automated checks are used alongside keyboard and responsive-layout reviews. We welcome reports from people using assistive technology so we can prioritise real barriers.
